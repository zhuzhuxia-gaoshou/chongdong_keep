## 0. 取用规则

| 规则 | 说明 |
|---|---|
| 确定性轮换 | `BrandCopy.pick(pool, seed:)`，种子缺省为**日序**（`daySeed`）：同一天恒定、隔天换新——有彩蛋感且可测试。成功类 toast 传业务量（时长/剩余卡数）作种子，让每次反馈略有不同。 |
| 语气符 | 每条 ≤ 1 个；只用品牌集 `🐾 💗 🥺 🌸`，`🎉` 仅限成就/庆典。禁 ✅ ❌ ⭐ 👍 等功能感符号。 |
| 语气 | 不命令（请/必须/不要/需）、不指责（错误/不正确/无效/有误）；以「哦/呀/呢/啦」收尾或用陈述句。 |
| 称谓 | 对宠物统一「宝贝」，对用户用「你」（不出现「您」），App 自称「宠动Keep」。 |
| 占位符 | `{min}` 分钟数、`{n}` 剩余补签卡、`{days}` 连续天数；由对应方法替换，页面不得自行拼接。 |
| 密度 | 同一 SnackBar / Dialog 只用一种 emoji；PageHero 副标题单行（≤ 24 字）。 |

## 2. 记录已存但未达 5 分钟 — `recordSavedShortPool` / `recordSavedShort(minutes)`

鼓励而非提醒不足；`{min}` 为本次分钟数。

| # | 文案 |
|---|---|
| 1 | 记录好啦，陪玩 {min} 分钟；满 5 分钟就能算打卡哦 |
| 2 | {min} 分钟的陪伴也很珍贵，下次凑到 5 分钟就打卡啦 🐾 |
| 3 | 已经记下 {min} 分钟啦，再多陪一会儿就能打卡哦 |
