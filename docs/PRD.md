## 一、产品概述

### 1.1 产品定位

**宠动Keep** —— 一款让铲屎官和宠物一起运动打卡、养成健康习惯的 APP（宠物版 Keep）。

- **一句话**: 记录宠物运动、管理宠物健康、和宝贝一起养成好习惯
- **核心闭环**: 遛狗/陪玩 → 记录数据 → 达标打卡 → 连续激励 → 分享传播
- **目标市场**: 国内，全中文，Android 优先（iOS 后续按需）

### 1.2 解决什么问题

| 用户痛点 | 我们的方案 |
|---|---|
| 工作忙，忘记遛狗/陪猫玩 | 运动记录 + 打卡连续天数激励习惯养成 |
| 不知道每天遛多久合适 | 按品种/年龄/体重计算推荐运动目标 |
| 遛狗无聊难以坚持 | 排行榜 + 徽章成就（二期） |
| 记录只能靠朋友圈发图 | 一键生成精美分享卡片 |
| 恶劣天气还出门遛狗 | 天气卡片 + 适宜度预警 + 室内替代建议 |
| GPS 断了/APP 被杀数据丢 | 本地快照 + 中断恢复（已实现）+ 弱网补传（已实现） |
| 运动中宠物出状况不知道怎么办 | 症状自查 + 高风险直跳就医 + 附近宠物医院（已实现） |
| 忘打卡浪费连续天数 | 补签卡机制（后端 ⑲ 接口待做） |

### 1.3 目标用户

- **核心**: 20-40 岁城市养宠年轻人（狗主人为主，猫主人其次）
- **次要**: 养多宠物的家庭、家人共同照护的家庭组（二期）
- **典型画像**: 新手铲屎官（需要指导每天遛多久）、独居加班族（需要提醒打卡）、健身达人（带狗跑步、看数据）

### 1.4 设计风格（已确认，不变）

- **视觉**: 清爽专业风——薄荷绿 `#4CAF50` 主色 + 米白 `#F5F5F5` 底 + 珊瑚橙 `#FF6B6B` 点缀
- **文案**: 温柔治愈风（多用「哦/呀/呢/啦」和 🥺💗🌸🐾，绝不命令式、绝不指责）
- **字号/圆角**: 正文 14sp / 标题 18sp / 大标题 24sp；卡片圆角 12px、按钮 8px

### 2.4 打卡判定统一规则（前后端必须一致）

- 任意一只宠物完成（≥5 分钟、已完成）= 用户当天打卡成功
- 同日多条运动只算 **1 次打卡**，时长可累加
- 不限运动类型：遛狗和猫玩都计入
- 补签卡只能补打卡状态，**绝不能**伪造时长/距离/排行数据（反作弊底线）

### 2.5 反作弊与隐私底线

- 排行榜默认主榜 = 运动总时长；单次 >6h 或速度 >60km/h 标记待核验不入榜
- 精确坐标/常住地/手机号/健康信息**绝不出现**在公开榜单
- 分享卡片精确位置默认隐藏；轨迹默认仅本人可见
- 权限按需索取：拒绝非核心权限后核心流程仍可用

### 阶段 1：后端 P1 + 前端 M4（依次点亮假数据页）

| 顺序 | 后端接口 | 前端页面 |
|---|---|---|
| 1 | ⑱ 今日打卡 + ⑲ 补签 | 首页今日进度切服务端；日历补签按钮接通 |
| 2 | ⑳㉑ 周报/月报聚合 | 周报页摘除硬编码（过渡期可先本地聚合） |
| 3 | ㉒ 排行榜 | 摘假名单（SQL 排序起步，量级上来再上 Redis） |
| 4 | ㉓ 徽章 | 摘假解锁态（服务端事件落库） |

同步收尾：出发照片上传打通（⑬ walkPhoto 分支）、D1-D5 不再重现（新后端直接按契约实现）。

### 阶段 2：体验深化

- 后台定位保活（前台 Service，遛狗锁屏不断）
- 暂停/继续按钮
- 分享卡片「保存相册」接真实现、轨迹缩略图用真实 route
- 设置页开关持久化、数据导出/删除/注销（合规要求）

### 阶段 3：二期——健康与社交

AI 健康咨询助手（先 UI+Mock，真实大模型后期）、动态运动目标（基础/建议/挑战三档）、家庭照护组、体重健康曲线、宠物时间线日记、品种专属建议、任务挑战、内容资讯。

### 阶段 4：三期——商业化（数据达标后启动）

宠物商城（CPS 跳链：淘宝/京东联盟）、训练计划课程、智能项圈接入、会员增值。

> 三期启动触发条件：7 日留存 >30%、周活用户运动记录 ≥2 次、分享转化率 >15%。
